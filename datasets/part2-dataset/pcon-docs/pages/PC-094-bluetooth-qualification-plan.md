# Bluetooth SIG Qualification Plan

| Field | Value |
|---|---|
| Page ID | PC-094 |
| Owner | Tobias Kern |
| Last updated | 2026-09-18 |

## Why

Every product using Bluetooth must be qualified and listed with the Bluetooth SIG before it is sold. The qualification must be completed before SOP.

## Approach

- Reuse the qualified design of the Nimbus BT Stack (Sylvan Wireless) and the controller module.
- Create an end-product listing for the HU4 head unit referencing these designs.
- Testing of profile-level conformance with the stack supplier's test reports.

## Profiles to be listed

| Profile | Version |
|---|---|
| HFP | 1.7 |
| A2DP | 1.3 |
| AVRCP | 1.6 |
| PBAP | 1.2 |
| MAP | 1.4 (only if REQ-017 is part of R1) |

## Responsibilities

- Owner: Tobias Kern.
- Test reports: Sylvan Wireless.
- Listing fees: Meridian program budget.

## Timeline

Preparation starts in Q4 2026. The listing is planned "before SOP".
