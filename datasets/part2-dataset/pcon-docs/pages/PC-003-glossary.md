# Glossary

| Field | Value |
|---|---|
| Page ID | PC-003 |
| Owner | Andrei Popescu |
| Last updated | 2026-08-14 |

| Term | Meaning |
|---|---|
| A2DP | Advanced Audio Distribution Profile – Bluetooth profile for media audio streaming. |
| ACL | Asynchronous Connection-Less link – the baseband link underlying a Bluetooth classic connection. |
| ADR | Architecture Decision Record. ADRs of this project are listed in PC-057. |
| AVRCP | Audio/Video Remote Control Profile – play/pause/skip and metadata. |
| B-Sample / C-Sample | Hardware/software maturity levels of the vehicle program. C-Sample is the last sample phase before SOP. |
| BT_READY | Internal event emitted by the BT Stack Adapter when the Bluetooth controller and stack are initialized and accept connection requests. |
| Comfort mode | Vehicle mode in which the infotainment system runs while the ignition is off. |
| DTC | Diagnostic Trouble Code. |
| HFP | Hands-Free Profile – phone calls through the vehicle. |
| HiL | Hardware-in-the-Loop test environment using the real head unit on a bench. |
| HSM | Hardware Security Module of the HU4 SoC, used for key wrapping. |
| HU4 | Fourth generation head unit, the target hardware of this project. |
| KL15 | Terminal 15, the ignition-on signal of the vehicle. |
| Link loss | Unintended loss of the Bluetooth connection while the vehicle is running. |
| MAP | Message Access Profile – access to SMS/messages on the phone. |
| MRU | Most Recently Used – priority rule for multi-phone handling. |
| PBAP | Phone Book Access Profile – download of contacts and call history. |
| Primary phone | The connected phone that owns HFP and media audio. |
| Secondary phone | A second connected phone; HFP only. |
| SiL | Software-in-the-Loop test environment, simulated Bluetooth peer and vehicle signals. |
| SLC | Service Level Connection – HFP connection setup between head unit and phone. |
| SOP | Start of Production. |
| SSP | Secure Simple Pairing. |
| Reconnection time | Duration from the defined start event to the moment the phone is connected. The start event is defined in REQ-002 (PC-013). |
| TARA | Threat Analysis and Risk Assessment (cybersecurity). |
