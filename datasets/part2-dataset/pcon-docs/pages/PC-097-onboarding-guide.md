## First day

1. Read the project overview (PC-001), scope (PC-002) and glossary (PC-003).
2. Request access (see below).
3. Meet your onboarding buddy (assigned by Andrei).

## First week

- Build the SiL environment locally (`make sil` in the repository root).
- Run the SiL smoke suite.
- Read the component pages of the components you will work on.
- Read the ADRs (PC-057).

## Lab work

Before working at the HiL benches, introduce yourself to Daniel Szabo, who explains the bench layout and the phone automation. The lab contains programmable power supplies up to 30 V/50 A.
