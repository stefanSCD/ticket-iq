## ADR process

1. Anyone can propose an ADR as a Jira issue of type *Decision*.
2. The author writes the page with context, options and a proposed decision.
3. The architecture sync (biweekly) discusses it.
4. Tobias Kern sets the status to Accepted or Rejected.
5. Superseded ADRs keep their page; the status is changed to "Superseded by ADR-xxx".

Open points listed inside ADRs are tracked as separate Decision issues.
