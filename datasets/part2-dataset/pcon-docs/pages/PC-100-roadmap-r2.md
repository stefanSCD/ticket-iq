## Candidate topics for R2

| Topic | Description | Status |
|---|---|---|
| Favourite phone | Driver selects a phone that is preferred over MRU | Requested by Product Management; relation to ADR-002 open |
| Driver identification | Select primary phone via user profile / key fob | Depends on HMI Platform user profiles |
| Guest / valet mode | Behavior of connectivity in restricted user modes | Requested by HMI Platform |
| Pairing in user profile | Pairing list stored per user profile, possibly synced via backend | Idea |
| LE Audio | Depends on Nimbus 5.3 or later | Idea |
| MAP with text-to-speech | Reading messages aloud | Depends on HMI Platform |
| Connectivity during OTA | Behavior of Bluetooth while a software update is installed | Raised by OTA team |
| Field analytics | Reconnection KPIs from the fleet via backend | Depends on diagnostics upload decision |

## Prioritization

R2 prioritization will be done in the planning workshop after the C-Sample release (January 2027). Inputs: customer clinic results, field test results (PC-080), effort estimates.

## Not planned

- Bluetooth for rear-seat entertainment.
- Wi-Fi Direct features.
