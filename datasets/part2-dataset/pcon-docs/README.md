# PCON – Phone Connectivity documentation corpus

- `pages/` – 100 Confluence-style pages (PC-001 … PC-100), English, Markdown. This is the retrieval corpus.
- `_meta/knowledge-registry.md` – answer key for ticket generation (resolved facts, open decisions, partial topics, conflicts). **Keep it out of the retrieval index.**

Built on the Bluetooth Reconnection KG PoC data (FEAT-001, REQ-001…007, COMP-001…005, TEST-001…010, EXEC-001…016, TRACE-001…010, DEF-001…003), extended into a full fictional project.
