# Returns and condition inspection — Staff FAQ

Document ID: `TN-RET-FAQ`  
Owner: Iris Popa, Operations Lead  
Status: Active  
Applies to: ToolNest 1.1  
Published: 2026-08-28T08:00:00Z

## Context

A return records physical receipt separately from condition inspection. Staff need to stop the loan clock when equipment arrives without prematurely making an uninspected unit available to the next borrower.

## Requirements and guidance

### TN-RET-FAQ-01

Staff should complete a return inspection within 8 staffed operating hours after receiving the unit.

### TN-RET-FAQ-02

A borrower has returned the unit when receipt is recorded even if staff inspect it later; inspection delay does not extend the loan.

### TN-RET-FAQ-03

A scan repeated after receipt shows the original receipt time, not a new return time.
