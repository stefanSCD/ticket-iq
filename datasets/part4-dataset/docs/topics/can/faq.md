# Cancellations and booking edits — Staff FAQ

Document ID: `TN-CAN-FAQ`  
Owner: Iris Popa, Operations Lead  
Status: Active  
Applies to: ToolNest 1.1  
Published: 2026-08-28T08:00:00Z

## Context

Cancelling a booking is a reservation operation and is distinct from returning borrowed equipment. The system must release inventory promptly while retaining enough history to explain who cancelled the request and why.

## Requirements and guidance

### TN-CAN-FAQ-01

Borrowers can leave the cancellation reason empty; reasons are optional for self-service cancellation.

### TN-CAN-FAQ-02

If the reservation has already been collected, record a return instead of cancelling it.

### TN-CAN-FAQ-03

A repeat click on Cancel shows the completed cancellation rather than creating a duplicate event.
