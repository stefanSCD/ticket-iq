# Audit records and data retention — Staff FAQ

Document ID: `TN-AUD-FAQ`  
Owner: Iris Popa, Operations Lead  
Status: Active  
Applies to: ToolNest 1.1  
Published: 2026-08-28T08:00:00Z

## Context

The audit trail explains sensitive actions without becoming a second copy of all borrower content. Operational retention and account deletion must preserve required transaction references while limiting unnecessary personal data.

## Requirements and guidance

### TN-AUD-FAQ-01

Operational audit events remain searchable for 365 calendar days before scheduled deletion.

### TN-AUD-FAQ-02

A request to delete an account cannot finish while a returned unit still awaits condition inspection.

### TN-AUD-FAQ-03

An audit viewer can see that an incident action occurred without gaining permission to view the incident's private evidence.
